# 분석 방법과 해석

## 랩 분류

이번 랩 직전의 베스트와 완료 랩의 차이 `이번 − 이전 베스트`를 사용합니다. 먼저 베스트를 갱신해서 차이가 0이 되는 오류를 피합니다.

| 분류 | 기본 기준 |
|---|---|
| 최초 | 이전 유효 베스트 없음 |
| 베스트 | 차이 < −0.05초 |
| 근접 | −0.05초 이상, 1초 미만 |
| 보통 차이 | 1초 이상, 3초 미만 |
| 큰 차이 | 3초 이상 |

차이는 소수 셋째 자리로 반올림한 값으로 분류합니다. 작은 음수라도 허용오차 안이면 근접으로 분류합니다. 입력된 베스트와 관측 완료시간에서 내부 베스트를 유지합니다. 새 세션·누락 카운터는 새 기준선으로 처리합니다. 이 처리와 엄격한 유효성 검증은 공개용 코어의 설계이며 운영 서비스 변경이 아닙니다.

## 거리 비교

두 랩의 겹치는 경로 거리 범위에서 선형 보간합니다. 시간 차이 그래프는 공통 시작점의 시간값을 각 랩에서 뺀 뒤 `비교 − 기준`을 그립니다. 섹터 합산 구간은 명시한 첫 경계~마지막 경계입니다. 그래프 전체 공통 구간과 섹터 구간이 다를 수 있어 둘 다 표시합니다.

섹터 시간은 끝 경계 시각에서 시작 경계 시각을 뺍니다. 모든 수치는 입력의 정렬 품질·표본 밀도에 영향을 받습니다. 합성 예제는 정확한 경로 좌표를 사용하지만 실제 GPS 품질을 입증하지 않습니다.

## 코너 요약

- 진입: 분석 기준점 −70m의 속도
- 최저: 기준점 ±40m 창의 표본 및 보간한 양 끝 중 최저
- 탈출: 기준점 +80m의 속도
- 구간 시간: −70m부터 +80m까지 150m 구간을 통과한 시간

이는 공식 코너 경계나 에이펙스 정의가 아닙니다. 최저가 창 경계에 있으면 `minimum_at_window_boundary=true`로 표시합니다. 전체 코너 최저라고 단정할 수 없습니다. 표본 사이의 숨은 최저를 재구성하는 모델도 아닙니다.

## 코칭 문장

관찰 문장은 출구 기준점 속도와 구간 시간을 함께 읽어 줍니다. 원인이나 최적 조작을 확정하지 않습니다. 브레이크·기어·그립·타이어·교통은 입력에 없으므로 해당 원인을 추정해서 말하지 않습니다. 출력은 한국어 텍스트이며 외부 TTS 전송은 없습니다.
