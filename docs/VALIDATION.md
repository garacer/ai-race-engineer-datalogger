# 공개 재현본 검증 기록

검증일: 2026-10-25. Windows / Python 3.12에서 수행했습니다.

```console
python -m unittest discover -s tests -v
```

결과: **24개 테스트 통과**, 실패 0. 테스트 본문은 `tests/`에서 확인할 수 있습니다.

검증 범위:

- 최초 관측에서 과거 랩을 다시 알리지 않는 동작
- 이전 베스트를 기준으로 한 새 베스트·근접·1초/3초 경계 분류
- 중복, 카운터 리셋, 누락 랩, 오래된 상태, 잘못된 정수와 NaN/무한대 처리
- 일정 속도의 독립적인 기준값으로 보간·섹터·코너 통과시간 검증
- 거리 중복·시간 역전·센서 범위·공통 구간 밖 외삽 거부
- 분석 창 경계에서의 최저값 표시
- HTML 사용자 입력 이스케이프와 파랑·주황 실선
- Pleos 스텁이 미구현 오류를 명시적으로 반환하는 동작
- 합성 데이터 재생성 및 배포용 복사본 일치
- 전체 CLI 실행으로 HTML·4개 SVG·요약 JSON·코칭 이벤트 JSON 생성

```console
python -m jev demo --output build/demo
```

결과: 정상 완료. 합성 두 랩의 분석 구간은 0~1000m이며, 시각화·섹터 3개·코너 분석 창 2개·분류 시나리오 15개 이벤트를 출력했습니다.

예시 수치: 합성 A 36.878459초 / 합성 B 36.523038초. 실제 주행 성능이 아닙니다.

공개용 텍스트에서 원본 접속 주소·실제 계정명·사용자 절대경로·SSH 키·토큰 패턴이 없는지 별도 검색했습니다. 합성 샘플 외의 CSV/JSONL, 원본 영상·음성·로그·체크포인트는 포함하지 않았습니다. 패턴 검색은 최종 사람 검토를 대신하지 않습니다.

이 기록은 공개 오프라인 코어의 검증입니다. Pleos SDK 호환, Android 실행, 최신 실주행 상태/음성 경로, 실차 안전성 또는 랩타임 개선을 검증하지 않았습니다.
