# 구현·검증 현황

## 공개 코드에서 재현 가능

- Python 표준 라이브러리만으로 합성 상태의 동적 랩 코칭과 섹터 이벤트 생성
- 공통 경로 거리 입력의 속도·페달·조향·시간 차이 그래프
- 섹터 통과시간과 명시적 코너 분석 창의 속도·구간시간
- 외부 자산 없이 열리는 HTML/SVG 리포트
- 경계값, 유효하지 않은 값, 리셋·누락, 수치 기준 및 CLI 통합 테스트

## 별도 장치 프로토타입의 증거

장치에서 사용자 코칭 서비스 배포, 분리된 과거 로그 재생, 음성 경로와 해설 영상 제작을 검증했습니다. 해당 원본 데이터·설정·음성·영상·개인 경로는 이 저장소에 포함하지 않습니다. 이 항목은 공개 샘플만으로 독립 검증할 수 없습니다.

실시간 상태 생산이 없는 관찰 기간의 서비스 건강 확인은 실제 최신 주행 이벤트의 음성 성공을 뜻하지 않습니다. 실제 주행 중 최신 상태→분류→운영 오디오의 종단 검증은 완료로 주장하지 않습니다.

## 미구현

- Android 앱·APK·차량 탑재
- 운전 상태에 따른 화면·음성 제한 정책, 센서 품질과 지연의 실차 검증
- 다중 랩의 반복성·통계적 유의성·일반화 성능 평가
- 주행 시간 개선이나 사고 감소 효과의 실증

“구현됨”, “별도 프로토타입 증거”, “제안/미구현”을 구분합니다. 본 저장소만으로 앱 개발 완료나 실차 효과를 주장하지 않습니다.
